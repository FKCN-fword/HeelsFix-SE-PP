HeelsFixNG - NPC 가구 보정 (Skyrim SE 1.5.97)

설치 전 확인:
- Skyrim SE 1.5.97 및 해당 버전의 SKSE64
- Address Library for SKSE Plugins (1.5.97용)
- RaceMenu 0.4.11 (NiTransform/SKEE 인터페이스 제공)
- SKSE Menu Framework

설치:
1. 이 ZIP을 MO2/Vortex로 설치합니다.
2. 게임을 SKSE로 실행합니다.
3. SKSE Menu Framework 메뉴에서 "Heels Fix Native" 섹션을 엽니다.
4. "NPC furniture correction"에서 NPC 보정 설정을 조정합니다.
5. 로그는 Data\SKSE\Plugins\HeelsFixNative.log에서 확인합니다.

이 배포판은 ESP/ESM/ESL 및 Papyrus 스크립트를 포함하지 않습니다. 플레이어 보정과 SexLab/P+ 연동은 제공하지 않습니다.

주의: 전체 플러그인의 실제 게임 내 작동은 사용자 게임 환경에서 검증해야 합니다. 빌드 성공만으로 가구 보정 작동을 보증하지 않습니다.
